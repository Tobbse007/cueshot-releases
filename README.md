# Cueshot for Mac — downloads

Signed builds of [Cueshot](https://cueshot.app), the menu-bar app that shows your coding
agent what you see: screenshots, screen recordings and dictation, delivered over MCP.

- **Latest release:** https://github.com/Tobbse007/cueshot-releases/releases/latest
- **Direct download:** https://github.com/Tobbse007/cueshot-releases/releases/latest/download/Cueshot.dmg
- **Requirements:** macOS 26 or later, Apple Silicon (M1 or later). Node.js only for the MCP server.

Each release carries the DMG, its SHA-256 checksum and the release notes from `CHANGELOG.md`.
Cueshot is free during early access; a paid plan comes later.

The source code lives in a separate, private repository. This repository holds only what
you download.
